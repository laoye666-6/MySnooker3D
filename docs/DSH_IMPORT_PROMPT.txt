■ 物理要点（容易改错，改动前必读）
1. 白球自旋（加塞）**不能靠 PhysX**，是 BallController 里自建的滑移摩擦模型（CueRollStep）；
   依赖三条硬约束：① 白球物理材质摩擦取 0；② 白球 angularDrag=0；
   ③ 高低杆非对称系数（G.SpinTopK=1.0 / SpinLowK=2.0），否则中低杆是"无旋滑行"死区。
2. 定标依据：球-台呢滑动摩擦 μ≈0.2；杆头击点极限 h≤0.5r → 高杆≤1.25×(v/r)、低杆≥-1.0×(v/r)。
   **白球速度任何时刻不得超过出杆初速**（用户明确要求，代码里有钳制）。
3. spinV=spinH=0（中杆）必须与旧版逐帧一致 —— 判断加塞实现对不对的第一道关。
4. 低速撞库"粘库" = Physics.bounceThreshold 太大 → 设 0.1。
5. 白球不可与棕球同点重生（PhysX 炸膛）；赋速度前必须 WakeUp()。
6. **袋口（v0.41 重做）四条硬约束**（详见 CONTEXT_SUMMARY 第六节）：
   ① 颚部是圆弧且与库边鼻线**相切**（相切 → 开口宽度不变 → 手感不回归）；
   ② 台面挖真洞（127 块 BoxCollider 拼成），洞口阶梯边缘会抛起高速球 → PocketLaunchGuard 钳掉向上分量；
   ③ 袋内衬 30mm 厚环墙、**开口侧低(-0.015)/后侧高(+0.045)**（低墙兜不住快球、高墙绕整圈会挡贴库球，
      只有这个形状能同时满足）；内径 ≥ 洞口半径+球半径+余量（取 洞口+36mm），否则球一进袋口就嵌进衬壁被崩飞；
   ④ 落袋判据 G.InPocket 必须"球一进洞口就成立"，不能等掉到某个深度
      （高速球在那之前已横移 0.29m，会撞袋壁/拼缝被顶飞出台面）。

■ 规则要点（v0.42/v0.43 两条真 bug 的教训）
1. 规则改动**必须**走 SnookerRules.cs + RuleTest 断言，不许把判定写进物理/UI 代码。
2. **读规则要逐字读动词**：WPBSA Section 3 Rule 3(h)(ii) 的 "a colour has been **played at**"
   只要求"击打过"、不要求打进 → 阶段切换与是否进球无关。旧版按"打进"切换，清彩阶段因此混乱。
   played / potted / struck 是三种不同条件。
3. **"任选彩球"必须按【指定】的那颗计分**（3(h)(i) "which, if potted, is scored"）；
   旧版无条件按进袋球加分 → "指定蓝球进绿球"被算成合法 3 分（应罚 5 分 + 回点）。
4. 条款号要按**当前规则书年份**核对：2024-25 版是 Section 3 Rule 3(g)/(h)、Section 2 Rule 11；
   旧编号 3(e)/3(f)(ii)/10.3 不存在。

■ 关键约束（踩坑精华，共 38 条详见 README）
1. MuMu 只认 arm64/x86_64 → 必须 IL2CPP；必须关闭引擎裁剪（stripEngineCode=false + link.xml）
2. 工程物理资产 m_SimulationMode 必须为 0；测试代码必须 try/finally 恢复（曾导致真机物理全冻）
3. uGUI 动态字体在部分机渲染空白 → 文字一律 IMGUI + 内嵌 DroidSansFallback
4. uGUI 中心锚定 y 向上 vs 设计坐标 y 向下：pos.y = 540 - 设计y；IMGUI CRect 的 cx 是中心不是边缘
5. **运行时创建的 UI 图形在真机不可靠**：Sprite.Create / new Texture2D 编辑器正常、真机不渲染
   → UI 图形优先用纯色块或内建资源
6. **不要在编辑器里调 Screen.SetResolution**（会卡死播放模式）；ShotTest 不能加 -quit/-batchmode，
   且跑时必须让 Unity 窗口保持前台（否则 GUI 白屏、协程不推进）
7. **编辑器测试与 APK 构建不可并行**（报 HandleProjectAlreadyOpenInAnotherInstance 并崩溃，
   需手工删 Temp/UnityLockfile）
8. **推送前必须先 git fetch**（曾 force push 覆盖用户网页编辑的提交）；
   `gh release create` 偶发把 release 建成 Draft 且**不附 APK** → 必须 `release view` 核对 assets，
   必要时 `release upload` + `release edit --draft=false`
9. 含中文的 .bat 在 GBK 控制台闪退 → 批处理保持纯 ASCII；PowerShell 调 gh 的 --jq 含引号会报错，用 --template
10. 本机 github.com 偶发不通（git tag push 会失败），但 **gh CLI 走另一条通道常可用**
    → 可用 `gh api repos/.../git/refs -f ref=refs/tags/vX -f sha=<sha>` 建 tag 兜底
11. 跑完 ShotTest 后编辑器会残留"无标题空场景"，下次启动按 Play 只有天空盒
    → 双击 Assets/Scenes/Main.unity 打开正确场景即可
