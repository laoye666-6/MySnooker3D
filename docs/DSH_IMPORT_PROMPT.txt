■ 物理要点（容易改错，改动前必读）
1. 白球自旋（加塞）**不能靠 PhysX**，是 BallController 里自建的滑移摩擦模型（CueRollStep）；
   它依赖三条硬约束，缺一个效果就被吃掉：① 白球物理材质摩擦取 0；② 白球 angularDrag=0；
   ③ 高低杆用非对称系数（G.SpinTopK=1.0 / SpinLowK=2.0），否则中低杆是"无旋滑行"死区。
2. 定标依据（实测文献）：球-台呢滑动摩擦 μ≈0.2（滚动阻力 0.005~0.015）；球重 0.17kg 对
   a=μ·g 无影响（质量约掉），故加速度只取 μg；杆头击点极限 h≤0.5r → 高杆≤1.25×(v/r)、
   低杆≥-1.0×(v/r)。**白球速度任何时刻不得超过出杆初速**（用户明确要求，代码里有钳制）。
3. spinV=spinH=0（中杆）必须与旧版逐帧一致 —— 这是判断加塞实现对不对的第一道关。
4. 低速撞库"粘库"= Physics.bounceThreshold 太大 → 设 0.1。
5. 白球不可与棕球同点重生（PhysX 炸膛）；赋速度前必须 WakeUp()。

■ 关键约束（踩坑精华）
1. MuMu 只认 arm64/x86_64 → 必须 IL2CPP；必须关闭引擎裁剪（stripEngineCode=false + link.xml）
2. 规则改动**必须**走 SnookerRules.cs + RuleTest 断言，不许把判定写进物理/UI 代码
3. 工程物理资产 m_SimulationMode 必须为 0；测试代码必须 try/finally 恢复（曾导致真机物理全冻）
4. uGUI 动态字体在部分机渲染空白 → 文字一律 IMGUI + 内嵌 DroidSansFallback
5. uGUI 中心锚定 y 向上 vs 设计坐标 y 向下：pos.y = 540 - 设计y；IMGUI CRect 的 cx 是中心不是边缘
6. **运行时创建的 UI 图形在真机不可靠**：Sprite.Create / new Texture2D 在编辑器正常、真机不渲染；
   连"导入 PNG 但给面板加 sprite"这次也复现了异常 → UI 图形优先用纯色块或内建资源
7. **不要在编辑器里调 Screen.SetResolution**（会卡死播放模式）；编辑器的播放模式在窗口失焦时
   可能暂停，跑自动截图脚本要用 Application.runInBackground = true + WaitForSecondsRealtime
8. **编辑器测试与 APK 构建不可并行**（会报 HandleProjectAlreadyOpenInAnotherInstance 并崩溃，
   需手工删 Temp/UnityLockfile）；ShotTest 不能加 -quit/-batchmode
9. **推送到 GitHub 前必须先 git fetch**（曾 force push 覆盖了用户网页编辑的提交）
10. 含中文的 .bat 在 GBK 控制台会闪退 → 批处理保持纯 ASCII；PowerShell 调 gh 的 --jq 含引号会报错，用 --template
11. 本机网络访问 github.com/uploads.github.com 偶发不通，APK 上传可能多次失败需重试（开 VPN 后正常）

■ 常用命令
:: 同步母本 → 工程（robocopy /MIR，只镜像 *.cs，会删工程内多余 cs）
cmd //c E:\Snooker\tools\sync.bat
:: 构建（-x86only 只编 x86_64，调试快；正式版双架构）
"E:\Program files\2022.3.62f3c1\Editor\Unity.exe" -batchmode -quit -nographics ^
  -projectPath "E:\Snooker3D" -executeMethod BuildGame.BuildAndroid -logFile "E:\Snooker\logs\build.log"
:: 四道回归（都不能加 -nographics 的只有 PhysTest 系；RuleTest 可加）
  -executeMethod RuleTest.Run        期望 PASS=54 FAIL=0 + ALL RULES OK
  -executeMethod PhysTest.SpinTest   期望 ALL SPIN OK
  -executeMethod PhysTest.CushionTest 期望三个 bounced=True
  -executeMethod PhysTest.Run        开球回归
:: 编辑器自动截图（带窗口，不加 -quit/-batchmode）
  -screen-width 1600 -screen-height 900 -executeMethod ShotTest.Run → shots\editor\*.png（9 张）
:: MuMu 安装/启动/截图（注意 Git Bash 下要 export MSYS_NO_PATHCONV=1）
  adb connect 127.0.0.1:16384
  adb -s 127.0.0.1:16384 install -r -t E:/Snooker3D/Builds/Snooker3D.apk
  adb -s 127.0.0.1:16384 shell screencap -p /sdcard/a.png && adb pull /sdcard/a.png 本地路径
