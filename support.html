常见问题

游戏是免费的吗？会不会有广告？
免费、无广告、无内购。项目以 MIT 协议开源，APK 从 GitHub Releases 直接下载，没有第三方分发渠道。
支持联机对战吗？
不支持，以后也未必会加。它的设计起点就是"一台手机、两个人、同屏轮流击球"——像真的站在同一张球台两侧。
有 iOS 版吗？
目前没有。项目基于 Unity，理论上可以跨平台，但开发者只有 Android 真机与调试环境，暂无 iOS 计划。
规则真的完整吗？
WPBSA 2024-25 全量实现，含 Miss 三选一、自由球、复位选项，由 65 条纯函数断言回归保护。已知未实现：Miss 累计三次判负、自由球裁判裁量——这些在仓库文档的"诚实差距清单"里有记录。
为什么模拟器里玻璃界面看起来不对？
磨砂玻璃在部分模拟器（如 GLES3 环境）渲染不完整，这是已知限制。验收环境是编辑器 + 真机——用真机看，它是对的。
怎么参与开发或反馈问题？
源码、构建指南与踩坑文档都在 GitHub 仓库；bug 与建议请提到 Issues。MIT 协议，欢迎 fork。
