■ 物理要点（容易改错，改动前必读）
1. 白球自旋（加塞）**不能靠 PhysX**，是 BallController 里自建的滑移摩擦模型（CueRollStep）；
   依赖三条硬约束：① 白球物理材质摩擦取 0；② 白球 angularDrag=0；
   ③ 高低杆非对称系数（G.SpinTopK=1.0 / SpinLowK=2.0），否则中低杆是"无旋滑行"死区。
2. 定标依据：球-台呢滑动摩擦 μ≈0.2；杆头击点极限 h≤0.5r → 高杆≤1.25×(v/r)、低杆≥-1.0×(v/r)。
   **白球速度任何时刻不得超过出杆初速**（用户明确要求，代码里有钳制）。
3. spinV=spinH=0（中杆）必须与旧版逐帧一致 —— 判断加塞实现对不对的第一道关。
4. 低速撞库"粘库" = Physics.bounceThreshold 太大 → 设 0.1。
5. 白球不可与棕球同点重生（PhysX 炸膛）；赋速度前必须 WakeUp()。
6. **袋口（v0.41 重做）四条硬约束**（详见 CONTEXT_SUMMARY 第六节）：
   ① 颚部是圆弧且与库边鼻线**相切**（相切 → 开口宽度不变 → 手感不回归）；
   ② 台面挖真洞（127 块 BoxCollider 拼成），洞口阶梯边缘会抛起高速球 → PocketLaunchGuard 钳掉向上分量；
   ③ 袋内衬 30mm 厚环墙、**开口侧低(-0.015)/后侧高(+0.045)**；内径 ≥ 洞口+36mm，否则嵌进衬壁被崩飞；
   ④ 落袋判据 G.InPocket 必须"球一进洞口就成立"，不能等掉到某个深度。

■ 液态玻璃要点（v0.47 重做，改动前必读）
1. UIGlass = 零贴图顶点网格（圆角/胶囊/圆形/描边环），与纯色块同渲染路径——**真机 UI 禁用
   运行时贴图**（Sprite.Create/Texture2D 曾整块不渲染，踩坑 25）；网格 uv0 写入 [-1,1] 局部坐标，
   并在 OnPopulateMesh 把 _RectHW/_CornerR 推给 shader（圆角矩形 SDF 用，滑条等变尺寸元素随重建刷新）。
2. LiquidGlass.shader（v0.47 重写）：**重磨砂 + 边缘拉丝**的厚玻璃板质感——
   主体采 _GlassBlur（四分辨率+两轮分离高斯，GlassSceneCamera 用 GlassBlur.shader 产出），
   边缘 = 法向透镜（lens·band² 把界外内容拉进来）+ 切向拉丝（streak·band² 拖影，
   大面板 90px / 控件 44px）+ 顶部 sheen + 底部厚度阴影 + rim 细亮边 + 奶白 frost 提亮。
   _SoftMode 分支 = 纯色软边（专用于 AttachShadow 软投影）。
3. 场景源 = GlassSceneCamera（挂主相机的子相机，隔帧绘半分辨率 RT）。
   **场景采样三方案（GrabPass/相机命令缓冲/OnRenderImage）在 MuMu GLES3 上均间歇黑帧，
   编辑器 D3D11 全部正常——多相机渲染 + RT→RT Blit 是唯一确定性方案，别再试前三条路。**
4. **GLES 铁律：shader 里所有 pow() 底数必须 max(…,1e-4)**——pow(0,k) 部分驱动返回 NaN，
   曾把整片玻璃中心染黑（编辑器正常极具迷惑性；用"直接输出顶点色"的诊断构建定位）。
5. **踩坑 42：Fallback 会静默吞 shader 编译错误**——v0.44~45 的 shader 引用未定义变量
   编译失败，被 Fallback 平色掩盖两版。改 shader 后必须确认 Console 无 "Shader error"。
6. **踩坑 43：MuMu GLES3 不渲染多数玻璃元素（自带 CanvasGroup 的例外），真机正常**
   → 玻璃验收 = 编辑器截图（ShotTest）+ 真机，MuMu 不作数；定位手段 = shader 临时
   直接输出顶点色（踩坑 39 方法），验完立即还原。
6. 参数入口 = UIGlass.UseLiquid()（全参）；UseRefraction（控件预设：frost 0.36/拉丝 44px）与
   UseBlur（大面板预设：拉丝 90px）为映射，旧签名未变；游灯光源 _Glow 降为点缀（0.18/0.10）。
7. 软投影 = UIGlass.AttachShadow()（插元素正后方，随面板 CanvasGroup 淡入淡出）；
   独立淡入淡出的元素（中央提示胶囊/147 横幅）不要加投影。
8. 按钮交互 = UIJelly（按下压扁/松手欠阻尼过冲回弹，双轴刚度差=果冻扭动）
   + Haptics（按下轻点 12ms、主按钮确认 24ms；AndroidManifest 需 VIBRATE 权限）。
9. 字号一律引用 UIManager 的 FontXxx 常量阶梯（76/64/56/46/42/40/34/32/30/28/26），禁写字面量。
10. 设置弹窗：全屏暗色磨砂层（SettingsBlurBg）随 settingsCG 淡入 = 背景逐渐高斯模糊。

■ 规则要点（v0.42~v0.45 真 bug 的教训）
1. 规则改动**必须**走 SnookerRules.cs + RuleTest 断言，不许把判定写进物理/UI 代码。
2. **读规则要逐字读动词**：3(h)(ii) "a colour has been **played at**" 只要求"击打过"；
   played / potted / struck 是三种不同条件。
3. **"任选彩球"必须按【指定】的那颗计分**（3(h)(i) "which, if potted, is scored"）。
4. 条款号按 2024-25 版核对：球 on 顺序 = Section 3 Rule 3(g)/(h)；ball on 定义 = Section 2 Rule 11；
   指定球 = Section 2 Rule 12；罚分 = Section 3 Rule 11；犯规判定 = Rule 10；Miss = Rule 14；
   自由球 = Rule 12；旧编号 3(e)/3(f)(ii)/10.3 不存在。
5. **Miss 选框未做出选择前禁止击球**（v0.45 修复）：Rule 14(b) 的选择权必须先于下一杆行使、
   Rule 13 选择一经提出不可撤回。门禁 = GameManager.ChoicePending（BeginStrike/Shoot 拒绝）
   + 选框全屏透明挡板。Rule 14(b) 三选项中"原始位置重打"为简化未实现（沿用标注）。

■ 关键约束（踩坑精华，共 41 条详见 README）
1. MuMu 只认 arm64/x86_64 → 必须 IL2CPP；必须关闭引擎裁剪（stripEngineCode=false + link.xml）
2. 工程物理资产 m_SimulationMode 必须为 0；测试代码必须 try/finally 恢复（曾导致真机物理全冻）
3. uGUI 动态字体在部分机渲染空白 → 文字一律 IMGUI + 内嵌 DroidSansFallback
4. uGUI 中心锚定 y 向上 vs 设计坐标 y 向下：pos.y = 540 - 设计y；IMGUI CRect 的 cx 是中心不是边缘
5. **运行时创建的 UI 贴图在真机不可靠**（Sprite.Create/Texture2D/PNG）→ 玻璃用顶点网格（UIGlass）
6. **不要在编辑器里调 Screen.SetResolution**（会卡死播放模式）；ShotTest 不能加 -quit/-batchmode，
   且跑时必须让 Unity 窗口保持前台（建议再用 SetWindowPos HWND_TOPMOST 钉住）
7. **编辑器测试与 APK 构建不可并行**（HandleProjectAlreadyOpenInAnotherInstance，删 Temp/UnityLockfile）
8. **推送前必须先 git fetch**（曾 force push 覆盖用户网页编辑的提交）；
   `gh release create` 偶发建成 Draft 且不附 APK → 必须 `release view` 核对，
   必要时 `release upload` + `release edit --draft=false`
9. 含中文的 .bat 在 GBK 控制台闪退 → 批处理保持纯 ASCII；PowerShell 调 gh 用 --template 不用 --jq
10. 本机 github.com 偶发不通，gh CLI 常可用（用户开代理后 git push 亦正常）；失败先重试
11. 跑完 ShotTest 残留"无标题空场景" → 双击 Assets/Scenes/Main.unity 即可
12. **ShotTest 会把物理步长 0.5ms 持久化** → 下一轮编辑器 2000Hz 启动、首帧慢如卡死；
    已修（时间线开头回 2ms + Save + 150s 看门狗）；编辑器 PlayerPrefs 在注册表
    HKCU\Software\Unity\UnityEditor\SnookerLab\Snooker3D（键名为哈希形式）
13. **编辑器播放模式间歇白屏卡死**（协程全灭、无产出）→ 杀进程删锁重试，多数第二次即过；
    启动后立即 HWND_TOPMOST 钉窗可大幅减少
