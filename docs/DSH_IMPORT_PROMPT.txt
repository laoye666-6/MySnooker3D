■ 核心架构（三层分离）：
- SnookerRules.cs = 纯函数规则引擎（TableState + ShotFacts → ShotOutcome，不依赖物理/UI）
- GameManager.cs = 落地执行（加分/回点/换手/终局）+ 几何判定 IsSnookered()
- Editor/RuleTest.cs = 44 条离线规则断言；Editor/PhysTest.cs = 物理回归；Editor/BuildGame.cs = 命令行构建
其余：G.cs(常量) BallController(球) CueController(瞄准/出杆) AimLine(辅助线+指定彩球)
GameCamera(运镜) UIManager(uGUI 图形+IMGUI 文字) GameSettings(帧率/分辨率/阴影)

■ 关键约束（踩坑精华，改动前必读）：
1. MuMu 只认 arm64/x86_64 → 必须 IL2CPP；引擎裁剪必须关闭(stripEngineCode=false + link.xml)
2. 白球不可与棕球同点重生（PhysX 炸膛）；休眠刚体赋速度前必须 WakeUp()
3. 工程物理资产 m_SimulationMode 必须为 0——编辑器测试代码曾把它持久化导致真机物理全冻，
   测试代码必须 try/finally 恢复
4. uGUI 文字在部分机渲染空白 → 文字全用 IMGUI 绘制，中文用内嵌 DroidSansFallback
5. 低速撞库粘库 = bounceThreshold 太大；设 0.1
6. uGUI 中心锚定 y 向上 vs 设计坐标 y 向下：pos.y = 540 - 设计y；IMGUI CRect 的 cx 是中心不是边缘
7. **规则改动必须走 SnookerRules.cs + RuleTest 断言**，不许把判定写进物理/UI 代码
8. **推送到 GitHub 前必须先 git fetch**（我曾 force push 覆盖了用户网页编辑的提交）
9. 本机 Bash 是 Git Bash（路径 /e/Snooker）；含中文的 .bat 会闪退，需纯 ASCII；
   PowerShell 调 gh 时 --jq 含引号会报参数错误，用 --template
