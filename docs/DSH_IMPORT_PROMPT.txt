■ 物理要点（容易改错，改动前必读）
1. 白球自旋（加塞）**不能靠 PhysX**，是 BallController.CueRollStep 自建滑移摩擦模型；
   硬约束：白球材质摩擦 0 / angularDrag=0 / 非对称系数 SpinTopK=1.0、SpinLowK=2.0。
2. 定标：μ≈0.2；**白球速度任何时刻不得超过出杆初速**（用户明确要求；只钳速度不动自旋）。
3. spinV=spinH=0（中杆）必须与旧版逐帧一致 —— 第一道验收关。
4. 粘库 = bounceThreshold 0.1；白球不可与棕球同点重生；赋速度前必须 WakeUp()。
5. 袋口硬约束：颚弧与鼻线相切 / 真洞+PocketLaunchGuard / 内衬 30mm / InPocket 三层判据。
6. 任何"纯视觉"物体去碰撞体必须 **DestroyImmediate**（Destroy 帧末生效，离线测试会残留
   碰撞体污染回归——v0.56 实测 SpinTest 三断言因此全挂）。

■ 规则要点
1. 规则改动必须走 SnookerRules.cs + RuleTest（65 断言）；逐字读动词（played/potted/struck 三义）。
2. Miss 三选一（Rule 14(b)）：当前位置重打/原始位置重打（保留罚分）/自己打，由非犯规方选择；
   选框未选择前禁止击球（ChoicePending 门禁）。
3. 双方同意复位（非官方）：玩家1/2 各选同意·不同意，都同意才回退整盘含比分。

■ 液态玻璃 / UI 要点（v0.56 现行）
1. **不要给按钮/面板加 AttachShadow**（暗厅里读作"异常黑色圆角阴影"——用户报的 bug）。
2. 去白边/去绿闪靠 shader：控件 _Desat 0.60、面板 0.45、_Glow 0；边缘 alpha 必须乘法 a*(1+edge)。
3. 深色玻璃面板 + 全白字体；面板填充 alpha 0.52~0.70。
4. GLES 铁律：pow() 底数 max(…,1e-4)；Fallback 吞 shader 编译错误；MuMu 不作玻璃验收环境。
5. 动画：EaseTo 指数 ease-out，出比入快；弹窗 materialize；模态期间 HUD 整体让位。

■ 光影 / 相机要点（v0.56/57 新增）
1. **ACES 链**：主相机 targetTexture=sceneRT → 展示相机（depth+10/cullingMask=layer3）
   渲染 GradeQuad 做 ACES。禁止改回 OnRenderImage/帧缓冲拷贝（MuMu GLES3 黑帧）。
   四边形必须按屏幕宽高比拉伸，且创建时立即设尺寸（否则黑边+图像压缩）。
2. **反射探针必须 AllFacesAtOnce，且在创建球之前 RenderProbe**（否则球拍到自己的像）。
3. 俯身机位（0.42/0.11/0.55）与起立机位（1.55/0.85/1.15）参数都在 GameCamera.cs。
4. 吊灯参数在 Bootstrapper.BuildPcolLamp（罩 1.60~1.86、发光板 4.2）。

■ 工作方式约定（用户明确要求，务必遵守）
- 每轮给一组编号修改要求；versionName 0.NN = 第 NN 次迭代，versionCode 递增（在 BuildGame.cs 改）
- 物理/玩法 bug 先编辑器复现修复、回归通过再出 APK；中间迭代用 ShotTest 截图验证即可，
  最终打磨/发版阶段才上 MuMu；玻璃 UI 验收 = 编辑器 + 真机（MuMu 不作数）
- 改视觉模型尽量不动 C#；源码母本 E:\Snooker\unity_src 必须保留，改动先写母本再 sync
- 发版流程 = 改母本 → 改版本号 → 构建 → 同步 MySnooker3D → commit/push（先 fetch，抖动重试）→
  gh release（核对非 Draft+APK 在列）；已推送历史不改写，出 bug 直接发新版
- 代理（一元机场）连不上 GitHub 时放弃推送（用户授权过）；本地保留 commit
- 源码三副本：unity_src（权威）→ E:\Snooker3D\Assets（构建）→ MySnooker3D\UnityProject（仓库）
- 用户要求成品质量（不要"塑料游戏"），时间充裕多做迭代；最终交付需在 Unity 编辑器内打开验收
