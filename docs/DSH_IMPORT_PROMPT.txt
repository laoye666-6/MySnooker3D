■ 物理要点（容易改错，改动前必读）
1. 白球自旋（加塞）**不能靠 PhysX**，是 BallController.CueRollStep 自建滑移摩擦模型；
   硬约束：白球材质摩擦 0 / angularDrag=0 / 非对称系数 SpinTopK=1.0、SpinLowK=2.0。
2. 定标：μ≈0.2；**白球速度任何时刻不得超过出杆初速**（用户明确要求；只钳速度不动自旋）。
3. spinV=spinH=0（中杆）必须与旧版逐帧一致 —— 第一道验收关。
4. 粘库 = bounceThreshold 0.1；白球不可与棕球同点重生；赋速度前必须 WakeUp()。
5. 袋口四硬约束：颚弧与鼻线相切 / 真洞+PocketLaunchGuard / 内衬 30mm 厚·内径≥洞口+36mm·
   高低墙 / InPocket 三层判据"球一进洞口就成立"。

■ 液态玻璃要点（v0.47 现行）
1. UIGlass 零贴图顶点网格（**真机 UI 禁运行时贴图**）；OnPopulateMesh 推 _RectHW/_CornerR 给 SDF。
2. 双场景源 _GlassScene/_GlassBlur 都来自 GlassSceneCamera 副相机。
   **GrabPass/命令缓冲/OnRenderImage 在 MuMu GLES3 均黑帧——多相机+RT→RT Blit 唯一确定，勿再试。**
3. GLES 铁律：pow() 底数 max(…,1e-4)；Fallback 会吞 shader 编译错误（改完必须查 Console）；
   **MuMu 不作玻璃验收环境**（多数元素不渲染、真机正常；验收=编辑器截图+真机）。
4. 入口 UseLiquid()；AttachShadow() 软投影只挂随面板 CanvasGroup 淡入淡出的元素。
